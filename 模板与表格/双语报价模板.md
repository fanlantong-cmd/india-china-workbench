# 双语报价模板（中 / 英 / 印地）

> 复制改填即可。报价单是防跳单第一道闸——写清"含服务、渠道归我"。

## 中文版
```
【中印贸易报价单】
客户：______  日期：______
产品：______（印度采购，含一站式物流+清关）
数量：______  单价(人民币)：______  总价：______
交货期：______  付款方式：______（建议收30%定金）
报价含：印度采购 + 国际物流 + 中国清关 + 国内分发
特别说明：本渠道由我方独家提供，合作期间请通过我方对接供货方。
联系人：______（你的号，唯一对接入口）
```

## English
```
[China-India Trade Quotation]
Client: ______  Date: ______
Product: ______ (sourced in India, incl. full logistics + customs)
Qty: ______  Unit Price (RMB): ______  Total: ______
Lead time: ______  Payment: ______ (30% deposit recommended)
Includes: India sourcing + intl shipping + China customs + local delivery
Note: Channel provided exclusively by us; please contact supplier via us.
Contact: ______ (your number, sole point of contact)
```

```
मात्रा: ______  मूल्य (RMB): ______  कुल: ______
डिलीवरी: ______  भुगतान: ______ (30% एडवांस अनुशंसित)
शामिल: भारत खरीद + शिपिंग + चीन कस्टम + लोकल डिलीवरी
नोट: चैनल केवल हमारा; आपूर्तिकर्ता से हमसे ही संपर्क करें।

```
