# 防跳单约束协议（客户 / 供货商 通用）

> 复制改名字即可用。零预算、零法律门槛，先签再合作，震慑大于打官司。

```
中印贸易合作约束协议

甲方（服务方）：____________  乙方（客户/供货商）：____________
日期：____________

一、合作内容：甲方为乙方提供印度采购 / 中国物流 / 珠宝代购 一站式服务。

二、渠道保护：合作期间及结束后 12 个月内，乙方不得绕过甲方，
直接或间接联系甲方提供的供货方、物流方，不得私自成交。

三、违约罚则：乙方违反第二条，须向甲方支付违约金 =
该笔订单金额的 30% 或人民币 ______ 元（取高者），
并赔偿甲方已发生的采购、物流、差旅成本。

四、信息隔离：甲方提供的供货方联系方式、报价底价属商业秘密，
乙方不得记录、传播、转交第三方。

五、争议解决：友好协商；协商不成，提交甲方所在地法院。

签字：甲方________  乙方________  日期________
```

## 使用要点
- 新客户首次成交前发这份，简短说"公司规矩，所有合作都签"。
- 供货商版把"乙方"换成供货商，约束"不得私下接我客户"。
- 签了不等于高枕无忧，配合"只给成品不给源头"才稳。
