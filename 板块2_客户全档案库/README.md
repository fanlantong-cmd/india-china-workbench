# 板块2：项目｜客户全档案库

## 铁律
**所有客户数据云端留存，不交由家人私人保管。** 亲属只做执行（拣货、发货），不接触源头联系方式、不掌握客户清单。

## 结构
- `模板与表格/客户档案表.xlsx`
  - **客户总表**：每个客户一行（编号/来源/合作类型/累计成交额/状态/风险标记）。
  - **单客户跟进明细**：每个客户一个 sheet 或同表分行，存沟通、报价、订单、收款、交货节点。
  - **跟进话术库**：中英双语话术，复制即用。
- 风险标记字段专门记录：跳单、亲属私单、断供等。

## 用法
- 新客户 → 口述关键信息 → AI 建档 + 填总表。
- 每次沟通 → 口述摘要 → AI 追加跟进明细 + 拆待办。
- 成交/收款/交货 → 口述节点 → AI 更新状态。

## 合作风险记录（重点）
- 凡出现"客户学会渠道后跳单""亲属私接订单""供货商停单"，立刻在总表"风险标记"打标，并同步到 `板块7_专项防风险库/`，下次合作加约束。
