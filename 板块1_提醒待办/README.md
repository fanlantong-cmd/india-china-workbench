# 板块1：提醒｜待办事项（自动拆分）

## 作用
所有待办（客户跟进、库存整理、拍视频、对账）自动汇总到这里，标注截止时间和预估耗时。不再靠脑子记、不再漏跟进。

## 待办来源（AI 自动提取）
- **客户跟进**：来自客户档案的"待办动作"列。
- **库存整理**：来自你口述"今天整理了X件"或自动化2的进度提醒。
- **拍视频**：来自选题库 + 自动化3 的每日选题。
- **对账**：来自记账模块月末提醒。

## 每日固定打卡任务（AI 每日推送）
- 读书 30 分钟（生意/管理类，笔记存知识库）
- 运动 20 分钟（陪孩子也算）
- 听播客 10 分钟（贸易/自媒体类）
> 目的：服务你"平衡家庭、筹备二胎、工作减半"的年度目标，不是加负担，是充电。

## 用法
- 待办完成 → 口述"XX搞定了" → AI 自动移入复盘文档。
- 待办逾期 → 次日早推送标红提醒。
