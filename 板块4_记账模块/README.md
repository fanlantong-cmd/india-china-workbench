# 板块4：记账模块

## 作用
口述每日收支（货款、物流成本、理财收益、生活费…），AI 自动填 `每日记账流水表.xlsx`，生成月度/年度汇总和利润表。

## 用法
- 口述："今天收XX货款2万，付物流3000，理财到账500" → AI 填流水。
- 每月底自动化推送"月度收支汇总"，对比利润。
- 理财收益单独记（印度股票、定期），看清被动收入占比。

## 关键原则
- **生意账和家庭账分开**：工资/生活费单列，别混进货款，否则算不清真实利润。
- **每笔关联客户/订单**：方便追哪单赚、哪单亏。

## 表格
见 `模板与表格/每日记账流水表.xlsx`（记账流水 + 月度汇总 + 年度合计，公式自动算）。
