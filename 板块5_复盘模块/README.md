# 板块5：复盘模块

## 作用
自动生成周/月复盘，对比"工作减半、收入翻倍"年度目标进度。让你不瞎忙，看得见方向。

## 周复盘（每周一，配合自动化2）
- 客户成交：本周几个询盘、几个成交、漏跟几个。
- 错发货：本周错发/漏发几单，原因，改进。
- 自媒体：本周发几条、播放/私信数据。
- 库存：整理了X件，还剩Y件。

## 月复盘（每月底推送）
- 收入复盘：总收入、净利润、被动收入占比。
- 效率优化：哪些动作费时但产出低（如错发售后），下月砍掉/标准化。
- **年度目标进度条**：工作时长↓、收入↑ 各完成百分之几。

## 模板位置
- `板块5_复盘模块/周复盘模板.md`
- `板块5_复盘模块/月复盘模板.md`
- `板块5_复盘模块/年度目标追踪.md`

## 用法
AI 自动读记账/客户/库存数据生成，你只需看 + 口述"下月重点做XX"。
