# 板块3：知识库 & 技能库

## 作用
你口述/发文章/发培训资料/产品说明书/行业干货，AI 自动提炼核心、分类存入。遇到生意、拍摄、管理问题，优先调取知识库给落地操作。

## 四大分类（子文件夹）
- `贸易技能/`：选品、清关、物流、报价、反向贸易选品。
- `自媒体技能/`：脚本、拍摄、剪辑、选题、平台规则。
- `管理技能/`：团队、亲属约束、SOP、防跳单。
- `AI技能/`：怎么用 AI 口述归档、生成表格、写文案（你零基础，从这里起步）。

## 用法
1. 发链接/截图/口述干货 → AI 提炼存对应分类。
2. 遇到问题说"库存总乱怎么办" → AI 先搜知识库，命中即给方案；没命中才现想。
3. 每月 AI 自动把读书笔记、播客要点汇总进对应分类。

## 起步建议（今天就能做）
- 口述："我以前做珠宝中间商，客户学会渠道就跳单" → 存管理技能/防跳单。
- 发一篇印度清关文章 → 存贸易技能/清关。
