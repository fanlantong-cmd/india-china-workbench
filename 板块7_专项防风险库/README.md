# 板块7：专项防风险库

> 专门存三类要命的风险防护方案。每次出事，先来这里查，再决定怎么合作。

## 三大风险 + 对应文档
1. **客户学会渠道后跳单绕过你** → `防跳单方案.md` + `防跳单约束协议.md`
2. **亲属员工私下抢客户、私接订单** → `亲属私单约束规则.md`
3. **供货商停止向我供货（珠宝停滞）** → `独家壁垒方案.md`

## 使用铁律
- 任何新客户/新供货商合作前，先查本库对应方案，该签协议的签协议。
- 出现风险事件，立刻在客户档案表"风险标记"打标，并补充一条防护经验进本库。
- 协议模板直接复制改名字就能用，不花钱。

## 核心心法
**你的最大壁垒不是"知道渠道"，而是"渠道+物流+内容+服务"的组合别人复制不了。** 单点（比如一个供货商电话）容易被人拿走；组合拳拿不走。
